# Лабораторная работа №1: Статичная страница-визитка (Портфолио)

Одностраничный сайт-визитка, разработанный с использованием семантического HTML5, современного CSS3 (Flexbox, Grid) и адаптивной верстки под три брейкпоинта (Mobile, Tablet, Desktop).

## Реализованные проекты в портфолио
1. **IC GERALD REPAIR** — адаптивный лендинг для строительно-ремонтной компании (HTML5, CSS3, модульный JS, принципы DRY и SOLID).
2. **Веб-приложение поиска по ИНН** — интерактивный сервис на React для быстрой проверки и поиска информации по компаниям.
3. **Мой кинозал** — SPA-приложение на чистом JavaScript (поиск, фильтры, сортировка, избранное в LocalStorage и отказоустойчивые API-запросы).

## Технологический стек
* HTML5 (семантические теги)
* CSS3 (Grid, Flexbox, кастомные свойства)
* Git / GitHub (история коммитов, ветвление)
